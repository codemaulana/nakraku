# Discussion Guidelines & Categories

GitHub Discussions is our community space for questions, ideas, show-and-tell, and technical dialogue that does not constitute a reproducible bug report.

---

## 1. Categories Overview

| Category | Icon | Format | Intended Purpose |
|---|---|---|---|
| **Announcements** | 📢 | Read-only / Maintainers | Releases, roadmaps, security updates, and community news. |
| **Ideas & RFCs** | 💡 | Open Discussion | Architectural proposals, workflow suggestions, and design feedback. |
| **Q&A & Support** | 🙏 | Question / Answer | Troubleshooting, multi-monitor configuration questions, extension setup. |
| **Show and Tell** | 🙌 | Open Discussion | Share your desktop workflow setups, custom scripts, and integrations. |
| **General** | 💬 | Open Discussion | Open conversation regarding Windows productivity tools and Tauri v2. |

---

## 2. When to Use Discussions vs Issues

* **Use GitHub Discussions** when:
  * You have a general question about how Nakraku Stash works.
  * You need help getting the browser extension working in your browser.
  * You have an early concept or architectural idea that needs brainstorming.
  * You want to share how you configured your multi-monitor desktop.

* **Use GitHub Issues** when:
  * You have discovered a reproducible software defect or crash.
  * You have a specific feature request ready for roadmap scheduling.
  * There is a security vulnerability (or report confidentially via `security@nakraku.app`).

---

## 3. Community Standards in Discussions

* **Search Before Posting**: Many common questions regarding monitor clamping and Chrome MV3 service workers have already been answered.
* **Keep Discussions Respectful**: Adhere strictly to the [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md).
* **Mark Answers**: If someone helps resolve your question in Q&A, click **Mark as answer** to assist future users.
